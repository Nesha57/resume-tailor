# Pre-Class Technical Checklist

## Environment
- [ ] Python 3.10+ installed and accessible via `python` or `python3`.
- [ ] Virtual environment activated (`venv` or `conda`).
- [ ] `requirements.txt` installed (`pip install openai pydantic python-dotenv pytest`).

## API Access
- [ ] `GEMINI_API_KEY` is set in `.env`.
- [ ] Tested API connection with a basic script.
- [ ] Backup API key available in case of rate limits.

## Presentation Setup
- [ ] IDE font size increased to 18pt+.
- [ ] Terminal font size increased.
- [ ] Dark mode / Light mode chosen for room visibility.

## Code
- [ ] All solution scripts run without errors.
- [ ] Test suite passes (`pytest tests/`).
